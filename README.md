# My Studio

**YOUR CREATIVE SPACE — Твори без границ.**

Веб-приложение для редактирования фотографий, монтажа видео, создания мемов и оформления аватарок.

## Возможности

### Фоторедактор
- Загрузка PNG / JPG / WebP (кнопка + drag-and-drop)
- Коррекция: яркость, контраст, насыщенность, температура, оттенок, размытие, виньетка
- **Magic Enhance** — автоматическая коррекция
- 12 фильтров с регулируемой интенсивностью
- Поворот, отражение по горизонтали/вертикали
- Текст поверх изображения
- Режим «До / После» с ползунком
- Undo / Redo (Ctrl+Z / Ctrl+Y)
- Экспорт PNG и JPG с выбором качества

### Видеоредактор
- Загрузка MP4 / WebM (и других форматов, которые декодирует браузер)
- Воспроизведение, пауза, перемотка, громкость
- Обрезка начала/конца (trim)
- Скорость воспроизведения
- Фильтры (preview + export)
- Текстовые слои с временем появления/исчезновения
- Экспорт через **Canvas + MediaRecorder** → WebM
- Ограничение: один клип, без полноценного multi-track монтажа

### Генератор мемов
- Цветные/градиентные шаблоны + загрузка своего изображения
- Верхний и нижний текст (Impact-стиль, обводка)
- Стикеры-эмодзи
- Кнопка **«Случайный мем»**
- Экспорт PNG / JPG

### Редактор аватарок
- Загрузка фото, масштаб, поворот, перетаскивание
- Формы: круг, квадрат, скруглённый квадрат
- Фон (цвет / прозрачный для PNG)
- Неоновая рамка и свечение
- Экспорт 128 / 256 / 512 / 1024 px (PNG / JPG)
- Мини-превью для разных форм

### Общее
- 5 тем интерфейса (Neon Glass, Midnight Purple, Arctic Blue, Minimal Dark, Light)
- Сохранение проектов в **IndexedDB**
- Command Palette (Ctrl+K)
- Горячие клавиши: Ctrl+S (сохранить), Ctrl+Z/Y (undo/redo), Ctrl+T (тема)
- Адаптивный интерфейс
- Локальная обработка файлов (ничего не уходит на сервер)

## Запуск

### Локально

Приложение полностью статическое. Достаточно любого HTTP-сервера:

```bash
# Python
python -m http.server 8080

# Node (npx)
npx serve .

# VS Code Live Server и т.п.
```

Откройте `http://localhost:8080` в современном браузере (Chrome, Firefox, Edge, Safari).

## Публикация

1. Создайте репозиторий на GitHub и загрузите файлы.
2. GitHub Pages: Settings → Pages → Source: Deploy from branch `main` / root.
3. Либо Netlify / Vercel / Cloudflare Pages — перетащите папку проекта.

Все функции работают на статическом хостинге (нет серверной части).

## Известные ограничения

1. **Видеоэкспорт** — WebM через MediaRecorder. Качество и поддержка кодеков зависят от браузера. Длинные видео могут быть тяжёлыми для памяти.
2. **Проекты** — настройки и превью сохраняются; крупные медиафайлы (видео) не встраиваются в IndexedDB. При повторном открытии может потребоваться снова выбрать исходный файл.
3. **Кадрирование фото** — UI кнопок соотношений есть; полноценный интерактивный crop-rect в этой версии упрощён (трансформации работают).
4. **Sharpen** — ползунок есть, тяжёлая свёртка на каждый кадр не применяется в realtime (чтобы не тормозить).
5. Шаблоны мемов — цветные/градиентные заготовки (без чужих copyrighted изображений).

## Горячие клавиши

| Сочетание     | Действие              |
|---------------|-----------------------|
| Ctrl/Cmd + K  | Палитра команд        |
| Ctrl/Cmd + S  | Сохранить проект      |
| Ctrl/Cmd + Z  | Отменить              |
| Ctrl/Cmd + Y  | Повторить             |
| Ctrl/Cmd + T  | Следующая тема        |
| Esc           | Закрыть модал / палитру |
